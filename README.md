# Il s’agit d’un jeu inspiré du jeu “Wordle”.

L’objectif de ce jeu est de deviner le mot secret de quatre lettres. Pour cela, vous disposez de six tentatives. À chaque validation de tentative, vous pourrez voir les caractères qui étaient bons et bien placés et ceux qui étaient bons et mal placés changer de couleur.
Parviendrez-vous à trouver le mot secret ?

### Commande : 
Commande de lancement sur Git : 
```
deno task dev
ou
nmp run dev
```

Commande pour compiler le projet : 
```
deno task build
ou
npm run build
```

Commande pour ouvrir la prévisualisation : 
```
deno task preview
ou
npm run preview

```
